# Task Panel 0.2.0

## What's new

- Add `show_start_confirmation` and `show_stop_confirmation` configuration
  options. Disable either option to run that action immediately; both remain
  enabled by default.
- Rename the process-list panel to **Tasks**.

## Downloads

Release archives are available for Linux and macOS on `amd64` and `arm64`.
Verify downloaded archives with the included `checksums.txt` file.
